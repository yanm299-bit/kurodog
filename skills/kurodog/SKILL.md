# KuroDog · 小黑狗

Use the [official KuroDog Releases page](https://github.com/yanm299-bit/kurodog/releases/latest) for Windows x64. Use the selected release's actual asset links. The portable EXE ends in -windows-x64.exe and can run directly. The installer ends in -x64-setup.exe. Offer the portable version when the user has no preference.

Before running either EXE, compare its SHA-256 against SHA256SUMS.txt from the same release. In PowerShell, Get-FileHash -Algorithm SHA256 returns the checksum. If the download or its matching checksum is unavailable, report the problem and link to Releases. When the user requests installation or launch, open the verified EXE and confirm whether the pet window appeared or the installer opened.

For interaction help, use the pet's right-click menu or the KuroDog system tray icon. 缩放大小 controls size. With 锁定鼠标穿透 active, hold Alt to interact temporarily, or clear that setting in the tray menu. Move the pointer back and forth over the dog's head to trigger folded ears. 显示悬浮按键气泡 controls key labels.
